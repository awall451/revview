Calibration

CSS millimetres are not true millimetres on most monitors. Calibrate one of two ways; both set the same value. OS display scaling matters: use the resolution in CSS px (device pixel ratio ).

A. Monitor size
B. Credit card (85.60 x 53.98 mm)

Hold a real card against the screen and adjust until the outline matches.
